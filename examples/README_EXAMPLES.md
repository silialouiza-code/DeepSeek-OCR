# 📚 دليل الأمثلة - DeepSeek-OCR

هذا المجلد يحتوي على أمثلة عملية لاستخدام DeepSeek-OCR في سيناريوهات مختلفة.

---

## 📋 قائمة الأمثلة

### 1️⃣ example_1_basic_ocr.py
**استخراج نص بسيط من صورة**

- **المستوى**: مبتدئ
- **الوقت المتوقع**: 5-10 دقائق
- **متطلبات GPU**: 8GB

**ما ستتعلمه:**
- كيفية تحميل النموذج
- استخراج نص من صورة واحدة
- حفظ النتائج

**الاستخدام:**
```bash
python example_1_basic_ocr.py
```

**ملاحظة**: غير مسار الصورة في السطر 48:
```python
image_file = 'path/to/your/image.jpg'  # غير هذا
```

---

### 2️⃣ example_2_document_to_markdown.py
**تحويل مستند كامل إلى Markdown**

- **المستوى**: متوسط
- **الوقت المتوقع**: 10-15 دقيقة
- **متطلبات GPU**: 12GB

**ما ستتعلمه:**
- تحويل مستندات معقدة
- الحفاظ على التنسيق والجداول
- معالجة عدة مستندات دفعة واحدة

**الاستخدام:**
```bash
python example_2_document_to_markdown.py
```

**المخرجات:**
- ملف Markdown كامل
- صور مستخرجة من المستند
- صورة مع مربعات التحديد

---

### 3️⃣ example_3_pdf_processing.py
**معالجة ملفات PDF متعددة الصفحات**

- **المستوى**: متقدم
- **الوقت المتوقع**: 15-30 دقيقة
- **متطلبات GPU**: 16GB (موصى به)

**ما ستتعلمه:**
- تحويل PDF إلى صور
- معالجة متوازية للصفحات
- استخدام vLLM للأداء العالي

**الاستخدام:**
```bash
python example_3_pdf_processing.py
```

**خيارات المعالجة:**
1. vLLM (سريع، يحتاج إعداد)
2. Transformers (بسيط، أبطأ)

## 🐛 حل المشاكل

### مشكلة: "CUDA out of memory"

**الحل:**
```python
# قلل حجم الصورة
base_size = 512  # بدلاً من 1024
```

### مشكلة: "Model not found"

**الحل:**
```bash
# تأكد من الاتصال بالإنترنت لتحميل النموذج
# أو حدد مسار محلي
model_name = '/path/to/local/model'
```

### مشكلة: "Import error"

**الحل:**
```bash
# أعد تثبيت المكتبات
pip install --upgrade transformers torch
```

## 📝 تعديل الأمثلة

### تغيير مسار الصورة:

```python
# في جميع الأمثلة، ابحث عن:
image_file = 'path/to/your/image.jpg'

# وغيره إلى:
image_file = '/full/path/to/your/image.jpg'
```

### تغيير الأمر (Prompt):

```python
# للنص فقط:
prompt = "<image>\nFree OCR."

# للتحويل إلى Markdown:
prompt = "<image>\n<|grounding|>Convert the document to markdown."

# لوصف الصورة:
prompt = "<image>\nDescribe this image in detail."
```

### تغيير إعدادات الدقة:

```python
# للصور الصغيرة:
base_size = 512
image_size = 512
crop_mode = False

# للصور الكبيرة:
base_size = 1280
image_size = 1280
crop_mode = False

# للأداء الأمثل:
base_size = 1024
image_size = 640
crop_mode = True
```
